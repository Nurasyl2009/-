# Подключение WhatsApp

## Настройки

В локальном `.env` уже находятся токен и Phone Number ID. Не публикуйте файл.
Добавьте следующие поля:

```dotenv
WHATSAPP_APP_SECRET=
WHATSAPP_VERIFY_TOKEN=
WHATSAPP_ALLOWED_SENDERS=
```

APP_SECRET — секрет приложения Meta, в настройках приложения, обычно Settings → Basic → App secret.
Это отдельный секрет, не Access Token. Скопируйте его напрямую в локальный файл.
VERIFY_TOKEN — собственная случайная строка для проверки webhook (не токен API).
ALLOWED_SENDERS — ваш личный номер WhatsApp с кодом страны, только цифры, без +, например 77000000000.
Несколько номеров разделяются запятой. Остальные отправители игнорируются.

## Проверка

`python check_whatsapp.py` проверяет доступ к ID номера без отправки сообщений.
`python -m unittest -v` проверяет обработку диалогов и безопасность webhook на вымышленных данных.

## Приём сообщений

1. Заполните `.env` и запустите `python whatsapp_server.py`.
2. Опубликуйте localhost:8080 через HTTPS tunnel или разверните сервер с HTTPS.
3. В настройках WhatsApp приложения Meta укажите Callback URL: `https://ВАШ-АДРЕС/webhook`.
4. В Verify token вставьте ровно значение WHATSAPP_VERIFY_TOKEN из локального файла.
5. Подтвердите webhook и подпишитесь на поле `messages`.
6. Добавьте личный номер в разрешённые тестовые получатели кабинета Meta.
7. Напишите тестовому номеру `/start` со своего разрешённого личного номера.

Webhook проверяет HMAC-подпись через App Secret. Сервер слушает только localhost.
До заполнения секретов и списка отправителей сервер не запускается.
Текстовые ответы отправляются только на входящие запросы разрешённых номеров.
Аудио пока не распознаётся, файлы через WhatsApp не отправляются.

## Надёжность пилота

Входящие задания записываются в SQLite до HTTP-подтверждения. Повторный ID не обрабатывается дважды.
Каждый отправитель имеет отдельный диалог. Секреты и тексты не печатаются в журнал.
Данные переписки хранятся локально без шифрования в `work/whatsapp.sqlite3`.
После сетевой ошибки или аварии во время отправки статус `uncertain` требует ручной проверки:
автоповтора нет, чтобы не отправить ответ дважды. Новый `/start` сбрасывает диалог.
Статус `sent` означает принятие запроса API, не подтверждение доставки на телефон.
Уведомления о доставке пока игнорируются. Для публичной нагрузки нужен production HTTP-сервер,
мониторинг, управление сроками хранения и полноценная обработка статусов.

Сервер использует настраиваемую WHATSAPP_API_VERSION (по умолчанию v23.0).
Работа тестового номера не является одобрением Meta коммерческого AI-продукта.
